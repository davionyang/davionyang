# 🐍 贪吃蛇游戏

一个使用HTML、CSS和JavaScript编写的经典贪吃蛇游戏。

## 功能特点

- 🎮 流畅的游戏体验
- 🎨 现代化的渐变UI设计
- 📊 实时得分和最高分记录
- ⚡ 随着得分增加，游戏速度递增
- 🎯 支持多种键盘控制方式
- 💾 自动保存最高分记录

## 如何开始

### 在浏览器中打开

直接用浏览器打开 `snake-game.html` 文件即可开始游戏。

```bash
# 在Linux/Mac系统中
open snake-game.html

# 或者直接双击文件
```

## 游戏操作

### 控制方式

- **方向键**: ↑ ↓ ← → 控制蛇的移动方向
- **WASD键**: W(上) S(下) A(左) D(右)

### 按钮功能

- **开始游戏**: 开始新游戏
- **暂停/继续**: 暂停或继续当前游戏
- **重新开始**: 重置游戏到初始状态

## 游戏规则

1. 控制蛇吃掉红色的食物
2. 每吃一个食物得10分，蛇身变长
3. 每得50分，游戏速度会加快
4. 撞到墙壁或自己的身体会游戏结束
5. 最高分会自动保存在浏览器本地存储中

## 技术实现

- **HTML5 Canvas**: 用于游戏渲染
- **原生JavaScript**: 游戏逻辑实现
- **CSS3**: 现代化UI设计和动画效果
- **LocalStorage**: 保存最高分记录
